# Security policy

## Supported versions

The latest revision of `main` is the only supported development version. Jade is not currently distributed as a supported production service.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for sensitive security or privacy issues. Do not open a public issue containing exploit details, private recordings, imported documents, or other personal data.

Include the affected revision, device and OS version, reproduction steps, impact, and any suggested mitigation. Reports involving microphone access, document handling, local persistence, or exported files are especially helpful.
